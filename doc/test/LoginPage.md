## [x] 【前端元素】渲染登入頁面
**範例輸入**：無  
**期待輸出**：畫面成功渲染，包含 Email 輸入框、密碼輸入框與登入按鈕。

---

## [x] 【前端元素】已登入狀態導向
**範例輸入**：`isAuthenticated` 狀態為 `true`  
**期待輸出**：組件載入後自動導向至 `/dashboard` 頁面。

---

## [x] 【前端元素】顯示登入過期訊息
**範例輸入**：`authExpiredMessage` 有值（例如：「登入已過期」）  
**期待輸出**：畫面頂部顯示錯誤提示區塊（`error-banner`），包含該過期訊息。

---

## [x] 【function 邏輯】Email 格式驗證失敗
**範例輸入**：在 Email 欄位輸入 `invalid-email`，點擊登入  
**期待輸出**：不觸發 API 請求，並在 Email 欄位下方顯示錯誤訊息「請輸入有效的 Email 格式」。

---

## [x] 【function 邏輯】密碼長度驗證失敗
**範例輸入**：Email 輸入 `test@example.com`，密碼輸入 `123`，點擊登入  
**期待輸出**：不觸發 API 請求，並在密碼欄位下方顯示錯誤訊息「密碼必須至少 8 個字元」。

---

## [x] 【function 邏輯】密碼複雜度驗證失敗
**範例輸入**：Email 輸入 `test@example.com`，密碼輸入 `12345678`（僅數字）或 `abcdefgh`（僅英文字母），點擊登入  
**期待輸出**：不觸發 API 請求，並在密碼欄位下方顯示錯誤訊息「密碼必須包含英文字母和數字」。

---

## [x] 【Mock API】登入成功
**範例輸入**：輸入正確格式的 Email (`user@example.com`) 與密碼 (`Password123`)，點擊登入  
**期待輸出**：成功呼叫 `login` 函數，且成功後自動導向至 `/dashboard` 頁面。

---

## [x] 【Mock API】登入失敗顯示錯誤訊息
**範例輸入**：輸入正確格式但無效的帳密，點擊登入，API 回傳錯誤  
**期待輸出**：畫面頂部顯示 API 回傳的錯誤訊息（或預設的「登入失敗，請稍後再試」）。

---

## [x] 【前端元素】載入中狀態顯示
**範例輸入**：輸入正確格式帳密並點擊登入，等待 API 回應期間  
**期待輸出**：登入按鈕文字變為「登入中...」，且輸入框與按鈕皆設定為 `disabled` 狀態。
